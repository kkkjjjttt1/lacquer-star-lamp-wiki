AI / Computational Methods

项目：漆酶（Laccase）理性计算设计 —— 干实验部分，代码见 src/ai/，脚本与输出完整镜像于 xiangyuli-bio/Laccase。

本页描述本项目干实验部分使用的 AI / 计算方法。核心逻辑链：

  1. 要解决什么问题：在不破坏漆酶铜结合保守基序的前提下，对 533 aa 的漆酶序列提出少量、可解释、可验证的突变候选，用于提升热稳定性、50% RH 低湿度活性保持、漆酚（urushiol）氧化效率（kcat/Km）并降低残余酚类致敏风险。
  2. 与已有方案的差异：不采用端到端生成式设计或从头结构设计，而是"保守基序保护的规则化候选生成 + 预训练蛋白语言模型打分 + 单序列结构预测置信度验证"的可解释管线，输出 20 个高解释性候选，全部在本地可复现，不训练新模型。
  3. 如何验证有效：三层计算验证（ESM-2 突变兼容性、ESMFold 结构置信度、铜结合基序完整性），最终以湿实验酶活测定为金标准，通过 DBTL 闭环反馈（见 Integrated Validation）。

1. 任务定义 / Task Formulation

输入：533 aa 漆酶氨基酸序列（src/ai/deta/laccase_v2.fasta，来源：第二版方案书 2.docx，序列 ID laccase_v2）。

输出：20 个候选突变体（单/双点突变），按综合评分排序，附突变标签、设计类别、风险标志、理性依据与 ESMFold 预测结构（PDB）。

评估标准（计算阶段）：

  • 全部候选必须完整保留 HWHG、HPMHLH、HLHG、HCH 四个铜结合相关保守基序，且不改动任何 His/Cys 残基；
  • ESM-2 masked-marginal 突变兼容性 Δlog P > 0 为优，embedding 距离接近 WT；
  • ESMFold mean pLDDT ≥ WT（0.7305）为优；
  • 综合评分（四项加权归一化）用于最终排序。

设计约束（来自 src/ai/configs/design_v2.json）：

项目 设定
温度 30 ℃
相对湿度 50% RH
缓冲液 50 mM 柠檬酸-磷酸缓冲液，pH 5.5
底物 漆酚（urushiol），单烯、三烯优先
表达宿主 毕赤酵母（Pichia pastoris），与湿实验计划一致
致敏性关注 通过提高漆酚氧化效率降低残余酚类物质致敏风险；进入实验前筛查设计蛋白的明显致敏风险

2. 模型架构 / Model Architecture

2.1 整体框架

laccase_v2.fasta (533 aa)
        │
        ▼
[序列校验与统计] ──► 长度/氨基酸合法性校验、Kyte-Doolittle 疏水性、
│                     N-糖基化位点 (N-X-S/T) 检测
        ▼
[保守基序定位与保护] ──► HWHG(59-62)、HPMHLH(433-438)、HLHG(436-439)、HCH(495-497)
│                       全部 His/Cys + 基序邻域(±2) 禁止突变
        ▼
[规则化候选生成] ──► 四类设计目标：thermostability / low_humidity_activity /
│                    urushiol_pocket_tuning / combined（双突变）
        ▼
[ESM-2 650M 打分] ──► masked-marginal 突变 Δlog P + embedding 相似度（frozen）
        ▼
[ESMFold v1 结构预测] ──► WT + 20 候选 → 21 个 PDB，mean pLDDT（frozen）
        ▼
[综合排序] ──► 四项归一化加权 → final_ranking.csv → 湿实验候选清单

每个模块的输出都是下一个模块的输入；中间产物（候选表、评分、PDB、排序）归档于镜像仓库 outputs/ 下。

2.2 关键组件

组件 类型 是否原创 备注
序列校验与统计 规则脚本（src/ai/scripts，核心逻辑 src/proterin_design/sequence.py） 是 Kyte-Doolittle 疏水性、N-X-S/T 糖基化位点检测（排除 N-P-S/T）
保守基序保护 规则脚本 是 保护全部 His/Cys 与四个铜结合基序邻域（guard radius = 2）
候选突变生成 规则/启发式 是 四类设计规则 + 多样性配额选择（20 个，每候选 ≤2 突变）
ESM-2 esm2_t33_650M_UR50D 预训练蛋白语言模型（masked LM），frozen 否（facebook 开源，MIT） 突变兼容性打分与序列 embedding；模型归属见 Attributions
ESMFold v1 单序列结构预测模型，frozen 否（facebook 开源，MIT） WT + 候选结构预测与 pLDDT 置信度；模型归属见 Attributions
综合排序 加权归一化脚本（build_final_ranking.py） 是 min-max 归一化 + 四项加权（见 4.1）

2.3 关键运行参数

本项目不训练新模型，模型均为冻结推理，运行参数如下：

参数 值
ESM-2 / ESMFold 精度 bfloat16（CUDA）或 float32（CPU）；禁用 float16（验证时 pTM 计算不稳定）
ESMFold chunk size 64
模型加载 local_files_only=True，权重缓存于 models/huggingface/（不入库）
模型下载源 Hugging Face 镜像 https://hf-mirror.com（src/ai/configs/models_v2.json）
候选生成 每候选最多 2 个突变；同一位点突变最多复用 2 次；双突变位点间距 ≥ 8
随机种子 不涉及（无训练过程，管线确定性可复现）

2.4 计算资源

  • 推理硬件：单张支持 CUDA 的 GPU 即可（ESM-2 650M 与 ESMFold v1 均在单卡上完成，实际运行于 cuda:0）；无 GPU 时脚本自动回退 CPU
  • 推理时长：21 条序列（533 aa）的 ESM-2 打分与 ESMFold 结构预测在 GPU 上数小时内完成
  • 存储：模型权重（ESM-2 650M + ESMFold v1）约数 GB，缓存于本地 models/huggingface/

数据集 用途 样本量 来源 授权

本阶段为单蛋白定向设计任务，未使用外部酶活数据库；模型权重为第三方预训练产物，不在仓库内分发。

3.2 数据划分

  • 不适用：本阶段无监督训练 / 验证 / 测试划分；ESM-2 与 ESMFold 均为冻结模型，候选序列直接进入推理。
  • 候选集的构造受规则约束并做多样性配额选择（combined 30% / thermostability 25% / urushiol_pocket_tuning 25% / low_humidity_activity 20%），避免候选集中于单一目标类别。

3.3 数据预处理

  • 氨基酸合法性校验（仅 20 种标准氨基酸）与长度校验；
  • 序列统计：全长 533 aa，平均疏水性 −0.153，N-糖基化基序起始位点 15 处（5, 14, 28, 124, 180, 194, 233, 274, 284, 347, 364, 381, 398, 454, 519）；
  • 突变应用与标签解析（A123B 格式，多突变以 + 连接），确保突变标签与 WT 序列严格一致。
  • 输入数据指纹（SHA-256）见 Verifiability §2.4。

4. 训练与评估 / Training & Evaluation

4.1 评分函数

本阶段无模型训练，使用两类评分函数进行候选评估：

① 规则启发式设计分（候选生成阶段）

  • 热稳定性（thermostability）：柔性残基替换以提高局部刚性，如 G→A（基准 2.4 分，降低局部骨架柔性）、G→P（2.1，环区刚性化）、N/Q→D/E（2.2，降低脱酰胺倾向）、S/T→A（1.7）等；局部疏水性过低时扣 0.15。
  • 低湿度活性（low_humidity_activity）：脂肪族残基（A/V/I/L）→ S/T，增强局部极性以支持 50% RH 下的水合，得分 1.55 + 0.2 × max(0, 0.4 − 局部疏水性)。
  • 漆酚口袋调节（urushiol_pocket_tuning）：距保守基序中心 7–18 aa 的极性/带电残基 → F（疏水芳香）或 L，得分 2.0 − 0.035 × (距离 − 7)，以改善长链漆酚进入活性位点邻近区域。
  • 组合双突变（combined）：不同类别单突变配对（位点间距 ≥ 8），得分 (s₁ + s₂) × 0.88。
  • 惩罚项：新增 N-糖基化位点每个 −0.4；移除糖基化位点每个 −0.2。

② ESM-2 masked-marginal 突变兼容性分
对突变位点做掩码后，用模型预测该位点的 token 分布：

$$\Delta \log P = \log P(x_i = \text{replacement} \mid X_{\setminus i}) - \log P(x_i = \text{original} \mid X_{\setminus i})$$

Δlog P > 0 表示替换残基在 WT 序列上下文中比原残基更被模型"认可"（序列兼容性更高）。同时计算整条候选序列与 WT 的 embedding 相似度（最后一层隐藏状态均值池化后的余弦距离 / L2 距离），距离越小表示候选在表征空间中越接近 WT。

③ 最终综合排序（min-max 归一化后加权）：

composite = 0.35 × heuristic_norm
          + 0.30 × esm2_delta_norm
          + 0.25 × plddt_norm
          + 0.10 × embedding_conservativeness_norm

4.2 评估指标

指标 定义 与项目目标的关系
ESM-2 Δlog P（sum/mean） 掩码边际对数概率差之和/均值 反映突变与 WT 序列上下文的兼容性
Embedding 距离 候选 vs WT 表征余弦距离 / L2 距离 反映候选在序列空间中的保守程度
ESMFold mean pLDDT 结构预测残基置信度均值 反映突变未破坏整体折叠可信度
基序完整性 四个铜结合基序 + His/Cys 是否保留 直接保障铜离子结合与催化核心不被扰动
综合评分 四项归一化加权和 计算阶段的端到端优先级排序依据

4.4 不确定性与失败模式

  • 置信度报告方式：使用 ESMFold mean pLDDT 作为结构置信度（WT 0.7305，Top 候选 0.7383，Δ≈+0.008），该差异处于模型噪声范围内，因此仅用于优先级排序，不作为结构稳定性结论。
  • 已知失败/风险模式：
    • 多数 combined 双突变候选 ESM-2 Δlog P 为负（−5 ~ −7.5），说明按掩码边际分布，双突变组合的序列兼容性低于 WT；综合排序中由规则分与 pLDDT 部分补偿，但湿实验应优先验证 ESM-2 正分候选（如 CAND-011、CAND-012、CAND-007）。
    • 所有候选均带风险标志：structure validation required（结构验证必需）或 active-neighborhood heuristic（活性邻域启发式），提示需人工检查铜结合位点几何与邻近构象。
    • 含 Pro 突变或糖基化位点变化的候选被附加标志，需要二级结构/糖基化复核。
    • ESMFold 在 float16 下 pTM 计算不稳定，必须使用 bfloat16 / float32。

5. 复现指南 / Reproducibility

在仓库根目录依次运行（详细说明见 Verifiability）：

# 1) 候选生成（序列校验 → 基序保护 → 20 候选 → CSV/FASTA/报告）
python3 src/ai/scripts/run_design.py

# 2) 下载并验证本地模型（ESM-2 650M、ESMFold v1，权重不入库）
python3 src/ai/scripts/download_models.py
python3 src/ai/scripts/verify_models.py

# 3) ESM-2 打分（masked-marginal + embedding）
python3 src/ai/scripts/score_esm2.py

# 4) ESMFold 结构预测（WT + 20 候选 → 21 个 PDB）
python3 src/ai/scripts/predict_esmfold.py

# 5) 最终综合排序
python3 src/ai/scripts/build_final_ranking.py
  • 模型依赖：torch 2.6.0+cu118、transformers 5.13.1、huggingface_hub、accelerate、safetensors、biopython、pandas、scipy（见镜像仓库 requirements-models.txt）；本仓库根目录 requirements.txt 为通用模板，尚未包含上述版本，待更新
  • 模型缓存：models/huggingface/（.gitignore 排除），下载端点 hf-mirror.com
  • 单元测试：test/test_design_pipeline.py（6 个用例）
  • 完整复现与验证说明：见 Verifiability

6. 与湿实验的衔接 / Coupling with the Wet Lab

本阶段计算输出的湿实验接口：

  • 模型输出 → 湿实验候选清单：Top 候选见 §4.3（完整清单见镜像仓库 outputs/v2_final_ranking/final_ranking.csv，含突变、综合分、pLDDT、风险标志、理性依据与 PDB 路径）
  • 进入湿实验前的必做检查：
    1. 检查铜结合基序几何与邻近替换是否影响铜配位；
    2. 判断每个替换位点处于溶剂暴露面还是疏水核心；
    3. 筛查合成与表达可行性，包括糖基化变化；
    4. 与 PI / 安全负责人复核残余漆酚氧化测定设计与蛋白致敏性筛查方案。
  • 湿实验结果 → 模型反馈：湿实验酶活 / 稳定性数据将作为标签回填（DBTL 闭环的 Learn 阶段），用于下一轮规则权重与候选筛选的校准；详细闭环设计见 Integrated Validation。

7. 局限与未来工作 / Limitations & Future Work

当前局限

  • 分数是序列层面的优先级排序启发式，不是活性 / 稳定性预测；20 个候选尚未经湿实验验证，pLDDT 差异处于模型噪声范围。
  • 未进行本地微调：ESM-2 / ESMFold 均为冻结模型，未利用漆酶专属数据适配。
  • 未做基于结构的活性位点建模（如底物对接、分子动力学），漆酚口袋调节仅为序列邻域启发式。
  • AlphaFold 3、RFdiffusion2、ProteinMPNN 等近三年新方法未本地复现，仅作方法学对照。

未来工作

  • 湿实验验证后，用实测数据校准启发式权重，形成"预测 → 实验 → 回填"闭环；
  • 引入基于结构的评估（对接 / MD 模拟铜配位几何），将 ESMFold 结构用于活性位点约束的突变筛选；
  • 视许可与算力情况引入 AlphaFold 3 / ESM C 作为外部对照，评估是否值得本地部署；
  • 探索 ProteinMPNN 逆折叠在后续骨架设计中的用途（当前单酶点突变流程不需要）。
