漆星灯火 Wiki / 设计方案

Design

项目的整体设计逻辑——把"大目标"拆解成"具体可执行的子任务"。
实施细节见 AI / Computational Methods 与 Wet Lab / Experiments。

1. 设计原则 / Design Principles

  1. 保守优先（不破坏功能核心）：全部 His/Cys 残基及 HWHG、HPMHLH、HLHG、HCH 四个漆酶/多铜氧化酶铜结合保守基序及其邻域（±2）禁止突变，从源头避免破坏铜配位与催化核心。
  2. 可解释优先于黑盒：候选生成使用显式规则与理性依据（rationale），每个候选都附风险标志，不做"说不出为什么"的端到端生成。
  3. 小步、可验证：每候选最多 2 个保守点突变，先计算验证（ESM-2 兼容性、ESMFold 置信度）再进湿实验，降低无效实验成本。
  4. 干湿闭环（DBTL）：干实验输出候选 → 湿实验验证 → 数据回填校准 → 下一轮设计（详见 Integrated Validation）。
  5. 本地可复现：全部脚本入库、确定性管线、模型权重缓存不入库，任何人可复现（详见 Verifiability）。

2. 系统架构 / System Architecture

┌──────────────── 干实验（AI） ────────────────┐   ┌────── 湿实验 ──────┐

3. 关键技术决策 / Key Decisions

决策 候选方案 我们的选择 理由
序列生成方式 LLM 端到端生成 / Diffusion / 规则+模型打分 规则化候选生成 + 预训练模型打分 端到端生成缺乏可解释性与保守约束；规则+打分管线可保护铜结合基序、每个候选可解释、本地可复现（详见 AI-Computational-Methods §2）
突变范围 任意位点 / 保守位点 保护 His/Cys 与四个铜结合基序后，其余位点保守替换 最小化破坏催化核心的风险（design_v2.json protected_motifs）
突变规模 多位点组合 / 单双点 每候选 ≤ 2 个点突变，双突变位点间距 ≥ 8 便于归因单突变贡献、降低协同失效风险
打分模型 ESM-2 / ESM C / AlphaFold 3 ESM-2 650M（序列兼容性）+ ESMFold v1（结构置信度） 本地可运行、许可开放；ESM C / AlphaFold 3 因许可与算力未本地复现，列为后续对照
表达宿主 大肠杆菌 / 毕赤酵母 毕赤酵母（酵母） 队长确认湿实验采用酵母，与干实验设计配置 design_v2.json 一致
设计目标组合 单一目标 / 多目标 四类目标并行生成 + 多样性配额选择 覆盖热稳定、低湿度、漆酚氧化、致敏性降低四类需求

4. 风险与缓解 / Risks & Mitigations

风险 影响 我们的对策
突变破坏铜结合/催化核心 酶失活 全部 His/Cys 与四个铜结合基序邻域禁止突变；候选生成后校验基序完整（_motifs_preserved）
计算分数不代表真实活性 湿实验候选无效 分数明确标注为"优先级排序启发式"；湿实验前做结构复核与合成可行性筛查（AI-Computational-Methods §6）
糖基化位点变化影响表达 毕赤酵母表达异常 候选评分中新增/移除 N-糖基化位点均扣分，并附风险标志
双突变协同失效 组合候选反而更差 双突变位点间距 ≥ 8 且跨类别组合；多数 combined 候选 ESM-2 为负分，已如实记录并建议优先验证正分候选
模型环境不可复现 评审无法验证 脚本入库 + 依赖版本锁定 + 模型缓存不入库 + 数据指纹（见 Verifiability）
