Integrated Validation · 干湿结合验证

这一页讲述"AI 与实验如何对话"的闭环。当前闭环状态：Design 已完成，Build 处于质粒订购阶段，Test / Learn 因湿实验止步而未能开展（如实陈述，详见 Wet Lab / Experiments）。

1. 我们的 DBTL 闭环 / The DBTL Loop

Design  →  Build  →  Test  →  Learn
   ↑___________________________|
  • Design：干实验基于 533 aa WT 漆酶序列生成 20 个候选，经 ESM-2 + ESMFold + 综合排序得到 Top 候选（见 AI-Computational-Methods §4.3）
  • Build：已确定酵母（毕赤酵母）表达宿主，并向外部公司订购候选漆酶表达质粒（尚未到货）
  • Test：计划测定热稳定性、50% RH 低湿度活性、漆酚氧化 kcat/Km 与致敏性相关指标——未开展
  • Learn：实测数据回填 → 校准启发式权重与下一轮候选筛选——未开展（无实验数据）

2. 第一轮闭环 / Loop #1（当前状态）

环节 状态 详情
Design ✅ 已完成 20 个候选（4 类目标）；WT mean pLDDT = 0.7305；Top-1 CAND-011/G147A（综合分 0.7325，ESM-2 Δ=+0.5758，pLDDT 0.7383）
Build 🔄 质粒订购中 宿主：毕赤酵母；候选漆酶表达质粒已联系外部公司订购，尚未到货
Test ⛔ 未开展 受技术条件、经费与时间限制，湿实验止步于质粒订购阶段
Learn ⛔ 未开展 无实测数据产生，模型权重尚未校准

3. 局限 / Limitations

  • 当前分数为序列层面优先级排序，非活性预测；pLDDT 差异处于模型噪声范围（±0.008）。
  • 湿实验因技术条件、经费与时间限制未能开展，闭环尚未闭合；这是本项目当前最明确的局限。
  • 模型外推能力未知：ESM-2 / ESMFold 为冻结模型，未用漆酶专属数据微调。
  • 若后续质粒到货并完成表达验证，本页将如实更新 Test / Learn 结果与权重校准结论。
