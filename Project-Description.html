Project Description

1. 我们要解决的问题 / The Problem

现有生产体系下大漆生产效率受环境制约明显。我们希望通过该项目提高漆酶的活性，继而提升在不同环境因素下大漆的产量，
使得大漆能够真正为更广泛的人民群众说接受和体验，从而让这种传统的艺术形式飞入寻常百姓家。

2. 为什么 AI + 合成生物学是关键 / Why this approach

大漆的生产时十分复杂的过程，基于传统的生物学方法很难对漆酶进行优化；同时仅通过AI生成既没有实验的数据支撑，也缺乏了对成果的可行性验证，难以落地。
通过AI+合成生物学，一方面通过AI分析可行序列，指导实验的开展，提高实验的效率，加快项目的进行；另一方面实验的结果也为AI后续的训练提供了数据，使得AI分析出更合理的后续实验方向。

3. 我们的总体方案 / Our Approach

初期阶段，利用LLM设计并筛选出一些可能具有高活性的漆酶序列，从中选出最优的五个序列，用以指导后续实验工作的开展。
随后的第二阶段，即湿实验期间，针对这五个由干实验提供的高效候选漆酶序列，在毕赤酵母中进行表达，最终得出具体哪些酶的活性有所提高，并将这些数据反馈给AI，以便设计出新的酶序列。
在此“dblt”循环的进行下，最终获得真正能够提高活性的目标序列。

4. 预期产出 / Expected Outputs

1、方法体系与模式化方案
基于LLM辅助的漆酶序列设计、筛选、实验验证及反馈迭代，探索并总结一套可复用的酶序列优化流程，形成具有一定普适性的模式化研究方案和技术路径，为后续相关酶的理性设计与优化提供参考。
2、高活性目标菌株及关键突变类型
通过“干实验设计—湿实验验证—数据反馈—迭代优化”的循环，最终获得具有显著活性提升的目标菌株或优势漆酶突变体，明确能够有效提升酶活性的关键突变类型，为后续进一步应用和规模化研究提供实验基础。

5. 不解决什么 / Out of Scope

本研究主要聚焦于漆酶高产菌株及其关键突变类型的筛选与优化，核心目标是验证并提升目标菌株的产酶能力和酶活性。

对于后续实际生产工艺的落地、规模化应用条件优化，以及菌株在特定应用场景下可能产生的环境影响、生物安全性、人体过敏性等问题，不作为本研究的主要研究内容。
上述问题涉及工艺工程、生物安全及毒理评价等专业领域，超出本项目当前的研究能力与研究范围，因此暂不进行深入探讨。
