Verifiability

这一页回答：一个我们没见过的、有基本训练的同行，能不能在合理时间内复现我们的关键结果？
当前可验证的是计算（干实验）部分；湿实验部分待开展后补充。

1. 能验证什么 / What can be verified

关键结果 验证方式 预计时间
从 533 aa WT 序列生成 20 个候选（含基序保护与四类目标） 运行 src/ai/scripts/run_design.py < 10 分钟（无 GPU 亦可）
20 个候选的 ESM-2 打分（masked-marginal Δlog P + embedding 距离） 运行 src/ai/scripts/score_esm2.py（需下载模型） 取决于硬件，GPU 上约 1 小时内
WT + 20 候选的 ESMFold 结构预测（21 个 PDB + mean pLDDT） 运行 src/ai/scripts/predict_esmfold.py（需下载模型） GPU 上数小时
最终综合排序（四项加权） 运行 src/ai/scripts/build_final_ranking.py < 1 分钟
单元测试 运行 python3 -m pytest test/test_design_pipeline.py < 1 分钟
候选表达与酶活验证（湿实验） 未开展：湿实验止步于质粒订购阶段（见 Wet-Lab-Experiments） 视质粒到货与经费情况

2. 计算可验证 / Computational

2.1 一键复现脚本

# 仓库根目录
git clone <repo-url>
cd <repo-dir>

# 1) 候选生成
python3 src/ai/scripts/run_design.py

# 2) 模型下载与验证（权重缓存到本地 models/huggingface/，不入库）
python3 src/ai/scripts/download_models.py
python3 src/ai/scripts/verify_models.py

# 3) ESM-2 打分
python3 src/ai/scripts/score_esm2.py

# 4) ESMFold 结构预测
python3 src/ai/scripts/predict_esmfold.py

# 5) 综合排序
python3 src/ai/scripts/build_final_ranking.py

预期输出（截至 2026-09-01，与镜像仓库 outputs/ 一致）：

Top-1: CAND-011 / G147A / composite = 0.7325 / pLDDT = 0.7383
WT mean pLDDT: 0.7305
候选数: 20（combined 6 / thermostability 5 / urushiol_pocket_tuning 5 / low_humidity_activity 4）

2.2 环境

  • 干实验实际依赖：torch 2.6.0+cu118、transformers 5.13.1、huggingface_hub 1.23.0、accelerate 1.14.0、safetensors 0.8.0、biopython 1.87、pandas 2.3.3、scipy 1.15.3（镜像仓库 requirements-models.txt）
  • 模型下载端点：https://hf-mirror.com（src/ai/configs/models_v2.json）
  • 根目录 requirements.txt 与 Dockerfile 仍为通用模板，未锁定干实验实际依赖；干实验实际依赖见镜像仓库 requirements-models.txt（torch 2.6.0+cu118、transformers 5.13.1 等）

2.3 随机性控制

  • 本管线无训练过程、无随机采样（规则生成 + 冻结模型推理），结果确定性可复现，不依赖随机种子。
  • 注意：ESMFold 需使用 bfloat16 或 float32 精度；float16 会产生不稳定的 pTM 结果（README 记录）。

4. 过程可追溯 / Audit Trail

  • 代码版本：干实验脚本与配置已在仓库 src/ai/ 下版本化（镜像仓库 xiangyuli-bio/Laccase 含完整运行记录与输出）

  • 实验记录：湿实验未实际开展，暂无 ELN 记录（见 Wet-Lab-Experiments）

5. 我们做不到完美的地方 / Honest Limitations

  • pLDDT 差异（WT 0.7305 vs 最优候选 0.7383，Δ≈+0.008）处于 ESMFold 自身噪声范围，只用于优先级排序，不能作为"结构更稳定"的证据。
  • 多数 combined 双突变候选 ESM-2 Δlog P 为负，说明其序列兼容性低于 WT；复现时应预期并理解这一现象（见 AI-Computational-Methods §4.4）。
  • 模型权重需从 hf-mirror 下载（数 GB），首次复现依赖网络与磁盘空间。
  • 根目录 requirements.txt 与 Dockerfile 尚未与干实验实际依赖同步，是已知的复现短板。
